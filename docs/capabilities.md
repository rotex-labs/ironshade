# Capabilities

`ironshade-caps` will describe language and target requirements. A requirement
will resolve to Native, Lowered, Emulated, Unsupported, or Unknown. The compile
policy must explicitly permit emulation. Unsupported or unknown requirements
produce diagnostics.

See the [capability model](IRONSHADE_ARCHITECTURE.md#7-capability-model-ironshade-caps)
for the planned vocabulary, target limits, and capability reports.
