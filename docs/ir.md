# Ironshade Graph IR

The planned IR uses regionalized value and state edges. Text and graph
frontends both lower to this representation. Region boundaries retain
structured control flow, and explicit state edges order effects.

See [ADR 0001](adr/0001-graph-ir.md) and the
[IR design](IRONSHADE_ARCHITECTURE.md#5-ir-ironshade-graph-ir-igir) for the
planned node catalogue, builder, and verifier.
