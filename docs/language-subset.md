# Language subset

Ironshade has yet to implement shader parsing or compilation. As features land,
record whether each one is implemented, recognized and rejected, or unparsed.
The [language roadmap](IRONSHADE_ARCHITECTURE.md#14-language-roadmap-dependency-order)
defines the feature order and coverage gates.
