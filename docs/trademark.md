# Naming and trademark

Use Ironshade for the project, `ironshade` for the umbrella crate, and
`ironshadec` for the CLI. Library crates use the `ironshade-*` prefix.

Describe the project as aiming to compile the Slang™ shading language. Report
accepted language features and measured results against the pinned Slang
compiler test suite. Use the wording and notice specified in the
[naming section](IRONSHADE_ARCHITECTURE.md#13-naming-and-trademark-rules-docstrademarkmd).

Slang™ and the Slang logo are trademarks of the Khronos Group Inc.
